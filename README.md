# Popo Bali Tour

Landing page for Popo Bali Tour — private driver all over Bali.

Plain static site (HTML + CSS + vanilla JS), no build step.

## Deploy on Vercel
1. In Vercel, **Add New → Project** and import this repo.
2. Framework preset: **Other**. Leave build command and output directory empty.
3. Deploy.

## Before going live
- Set Popo's WhatsApp number at the top of `script.js` (`WHATSAPP_NUMBER`, with country code, e.g. `6281234567890`).
- Replace the `[PLACEHOLDERS]` in `index.html` / `script.js`: prices, seats, what's included, Popo's bio and photo, reviews, Google Maps link, Instagram reels.
